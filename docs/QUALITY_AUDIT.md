## 공통 변경

- 확대를 막던 `user-scalable=no`와 `maximum-scale=1.0`을 제거했습니다.
- 모든 게임에 항상 보이는 공통 홈 버튼을 추가했습니다.
- 아이콘형 음소거 버튼에 현재 상태와 실행 동작을 보조기기에 전달하도록 했습니다.
- 동적으로 생성되는 버튼도 기본 `type="button"`과 키보드 동작을 갖도록 했습니다.

## 확인 결과

- 14개 HTML과 7개 외부 JavaScript의 구문 검사 통과
- 메인 카드 13개와 모든 상대 파일 경로 검사 통과
- 13개 게임 모두 공통 홈 버튼 확인
- 캔버스가 있는 11개 게임 모두 접근성 이름 확인
- WebP 29개 디코딩 및 로컬 HTTP 응답 확인
- 모바일 390×844 환경에서 99일 생존·낚시 게임의 방향키와 동작 버튼 표시 확인
- 낚시 게임의 모바일 동작 버튼으로 `수면` → `던지는 중` 상태 전환 확인

## 다음 점검 때 권장하는 수동 플레이

자동 검사는 시작 화면과 핵심 입력 연결을 확인합니다. 게임 밸런스와 긴 플레이 흐름은 다음 항목을 실제로 플레이하며 확인하는 것이 좋습니다.

- 각 게임의 게임 오버·승리·재시작 흐름
- 모바일 가로 화면에서 HUD와 공통 버튼의 겹침
- iPhone 저전력 모드와 Android Chrome에서 오디오 재개
- 5분 이상 플레이 시 프레임 저하와 배경음 중복 여부
