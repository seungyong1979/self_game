# 🐰 리하의 토끼 키우기

> 💝 리하를 위해 특별히 만든 귀여운 토끼 육성 게임!

---

## 🎮 게임 소개

귀여운 아기 토끼 **"뽀뽀"** 를 돌봐주는 육성 시뮬레이션 게임입니다!
밥도 주고, 빗질도 하고, 목욕도 시켜주고, 같이 놀면서 토끼가 건강하게 자랄 수 있도록 도와주세요 🥕

---

## ✅ 구현된 기능

### 🐰 토끼 캐릭터
- SVG로 만든 귀여운 토끼 캐릭터
- **3단계 성장**: 아기 토끼 🍼 → 청소년 토끼 🌱 → 어른 토끼 🌸
- **10분 후 독립** - 그동안 돌봐준 점수로 결과 발표

### 📊 4가지 능력치
| 능력치 | 아이콘 | 설명 |
|--------|--------|------|
| 배고픔 | 🥕 | 당근을 주지 않으면 줄어듦 |
| 청결도 | 🛁 | 씻겨주지 않으면 낮아짐 |
| 행복도 | 💛 | 놀아주지 않으면 감소 |
| 성장도 | 🌱 | 시간이 지나면 자동 증가 |

### 💝 돌봄 액션
- **🥕 당근 주기** - 배고픔 회복, 먹으면 뚱뚱해짐
- **🪮 빗질하기** - 청결도 & 행복도 상승
- **🛁 씻겨주기** - 미니게임! 문질러서 씻겨주기
- **🤗 쓰다듬기** - 행복도 상승

### 🎮 놀이 액션
- **🎨 만들기 놀이** - 6가지 아이템 중 선택
- **⚽ 같이 놀기** - 행복도 크게 상승
- **🎵 노래 부르기** - 음악과 함께 행복하게
- **📚 책 읽어주기** - 상상력 쑥쑥

### 👗 옷 입히기 (9종)
| 종류 | 아이템 |
|------|--------|
| 모자류 | 🎀 핑크 리본, ⭐ 별 왕관, 🌸 꽃 머리띠, 🎉 파티 모자 |
| 몸통류 | 🎗️ 나비 넥타이, 👘 앞치마, 🧣 목도리 |
| 악세사리 | 👓 안경 |

### 🎭 토끼 감정 표현
| 상황 | 표현 |
|------|------|
| 행복할 때 | 눈이 하트 💗, 웃는 입 |
| 슬플 때 | 눈이 쓸쓸, 입이 내려감 |
| 심심할 때 | 하품 😪, 💤 말풍선 |
| 케어 받을 때 | 하트 뿅뿅 💕 |

### 🌟 비주얼 이펙트
- **더러울 때**: 💨 냄새, 🪰 파리 날아옴
- **깨끗할 때**: ✨ 윤기 반짝반짝
- **뚱뚱해지기**: 당근 너무 많이 먹으면 몸이 커짐
- **야위기**: 굶주리면 몸이 작아짐
- **레벨업**: 🎉 색종이 폭죽 + 토스트 알림

### 🎵 사운드
- Web Audio API로 만든 귀여운 배경음악
- 행동별 효과음 (먹기, 빗질, 목욕, 놀이, 성장, 독립)
- 🎵/🔇 버튼으로 음악 토글

### 🏆 결과 화면
- 100점 만점 점수 계산
- ⭐⭐⭐ 등급 평가
- 관심도에 따른 토끼의 작별 인사

## 🚀 실행 방법

`index.html` 파일을 웹브라우저에서 열면 바로 실행됩니다.
모바일(iPhone, Android) 브라우저에서도 완벽 호환됩니다!

---

## 📱 모바일 지원
- 터치 이벤트 완벽 지원
- 뷰포트 최적화 (user-scalable=no)
- 반응형 레이아웃 (clamp 함수로 유동적 크기)
- 터치 제스처로 목욕 미니게임 플레이 가능

---

## 🔧 게임 설정
- **게임 시간**: 10분 (아기→독립)
- **스테이지**: 45% → 청소년, 100% → 어른 & 독립
- **점수 계산**: 배고픔(40%) + 청결(35%) + 행복(25%) + 돌봄 보너스
