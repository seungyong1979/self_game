# 🐧 99일의 생존 - 펭귄의 얼음 모험

## 🎮 게임 소개

파란색 펭귄이 남극 얼음 위에서 **99일(297초)** 동안 생존하는 아이소메트릭 캐주얼 게임입니다.  
같은 자리에 오래 서 있으면 얼음이 깨져 바다로 떨어지고, 바다표범에게 잡혀 천사가 됩니다!

---

## ✅ 구현된 기능

### 핵심 게임플레이
- 🗓️ **99일 생존 시스템** - 3초 = 1일 (총 297초 생존 목표)
- ❄️ **아이소메트릭 3D 얼음 블록** - 육면체 형태의 입체적 얼음 타일
- 🐧 **펭귄 이동** - 9×7 격자 위에서 상/하/좌/우 이동
- 💀 **얼음 깨짐 시스템** - 3초 동안 같은 자리에 서있으면 얼음이 깨짐
  - 균열 3단계 시각화 (균열선 점점 심해짐)
  - 경고 색상 변화 (파랑 → 회색 → 갈색)
  - 빨간 플래시 경고 효과
- 🔄 **얼음 재생** - 깨진 얼음은 10초 후 재생 (재생 진행률 표시)
- 🪙 **동전 수집** - 펭귄 그림이 그려진 동전 수집 (+10점)
- 🦭 **바다표범** - 얼음 아래로 떨어지면 바다표범이 등장
- 😇 **천사 애니메이션** - 죽으면 펭귄이 천사가 되어 하늘로 올라감

### 비주얼
- 🌌 **남극 배경** - 오로라, 별, 산맥 실루엣, 눈 내리는 효과
- 🌊 **바다** - 얼음 아래 애니메이션 물결 표현
- ✨ **파티클 효과** - 얼음 파편, 동전 수집 이펙트, 재생 반짝임
- 🌅 **시간대 변화** - 날이 지날수록 점점 어두워짐 (후반부)

### 사운드 (Web Audio API)
- 🎵 **배경음악** - 펜타토닉 스케일의 신비로운 분위기 음악
- 💨 **바람 소리** - 남극 분위기 앰비언트 사운드
- 🔊 **효과음**: 발걸음, 얼음 균열, 얼음 파괴, 동전 수집, 물 낙하, 바다표범, 천사, 승리 팡파레 등

### 컨트롤
- ⌨️ **키보드**: 방향키 (↑↓←→) 또는 WASD
- 📱 **모바일 D-PAD**: 화면 하단 방향 버튼
- 👆 **스와이프**: 게임 캔버스에서 스와이프 제스처 지원
- 🔇 **사운드 토글**: 우측 상단 버튼

### UI/UX
- 📊 **HUD**: 현재 날짜(DAY 1/99), 점수, 다음 날까지 남은 시간 바
- 🏆 **승리/게임오버 화면**: 생존 일수, 최종 점수 표시
- 📱 **반응형 디자인**: 모바일/태블릿/PC 모두 지원

---

## 🎯 게임 방법

1. 방향키(또는 D-PAD)로 펭귄을 이동시키세요
2. 같은 자리에 오래 서있으면 얼음에 균열이 생깁니다
3. 균열이 심해지면 얼음이 깨져 바다로 떨어집니다
4. 동전(🪙)을 먹으면 10점씩 점수가 올라갑니다
5. 99일(297초)을 버티면 승리!

## 📁 파일 구조

```
index.html          - 게임 메인 HTML
css/
  style.css         - 전체 스타일 (배경, HUD, 오버레이, 반응형)
js/
  sound.js          - 사운드 매니저 (Web Audio API)
  game.js           - 메인 게임 로직 (캔버스 렌더링, 게임 상태)
```

## ⚙️ 기술 스택

- **HTML5 Canvas** - 아이소메트릭 렌더링
- **CSS3** - 애니메이션, 반응형 레이아웃
- **Vanilla JavaScript** - 게임 로직
- **Web Audio API** - 실시간 사운드 생성
